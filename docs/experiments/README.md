# docs/experiments/

Experiment logs organized by date. Each subfolder is a day (`YYYY-MM-DD`), containing numbered experiment files that record what was run, what was observed, and what was concluded.

## Subfolders

- **[2026-04-27/](2026-04-27/)** — Pilot runs for blunt trait vector extraction on A6000 GPU

## Convention

- One subfolder per day: `YYYY-MM-DD/`
- Files numbered sequentially: `01-description.md`, `02-description.md`, ...
- Each file records: purpose, parameters, timeline, observations, results, next steps
- Append new experiments as numbered files; do not overwrite previous entries
