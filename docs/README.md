# docs/

Project documentation for the I-and-Thou Vector research.

## Folders

- **[plans/](plans/)** — Experiment plans and approach documents. What we are going to do, what we are currently doing, and the rationale behind decisions. Start here to understand ongoing work.

- **[experiments/](experiments/)** — Experiment logs organized by date. Each run records parameters, timeline, observations, and results. Go here to see what has been tried and what was learned.

## Files

- `reproduction-guide.md` — How to reproduce the full pipeline (generation → extraction → steering)
- `paper-improvements.md` — Notes on improving the research paper
- `run-sh-*.md` — Documentation for the shell-based experiment runner scripts
- `session-handoff.md` — Context for handing off work between sessions
